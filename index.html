❓ How to Use

Quick Start
1️⃣
Set your RPM and unitsEnter the machine running speed and select your amplitude units (in/s, mils, etc.) in the top bar.
2️⃣
Configure componentsDriver is on the left (typically a motor), Driven is on the right (pump, fan, etc.). Set the coupling side for each.
3️⃣
Enter measurementsFor each sensor, enter the 1× amplitude and phase angle. Mark your fixed reference sensor with the Reference checkbox.
4️⃣
Check the Chart tabBubbles appear color-coded by severity. Green = normal, amber = warning, red = fault.
5️⃣
Read the Diagnosis tabAutomated fault analysis updates in real time as you enter data.
Sensor Positions
🔵
Axial DE (Drive End)At the coupling end of the shaft. Most important for angular misalignment diagnosis.
⚪
Axial NDE (Non-Drive End)At the free end of the shaft. Used for bent shaft / axial phase reversal check.
↕️
Vertical DE / NDEVertical sensors at each bearing. Used for radial misalignment, imbalance, and soft foot.
↔️
Horizontal DE / NDEHorizontal sensors at each bearing. V and H are 90° apart physically — ~90° phase between them is normal.
Sensor Orientation (Axial only)
➡️
InboardSensor face points toward the coupling. The app corrects this before phase comparisons.
⬅️
OutboardSensor face points away from the coupling (toward free end). Most common mounting.
Chart Features
👆
Long press a bubbleHold any bubble on the chart for half a second to see full sensor details.
📌
Add annotationsLong press on empty chart space to drop a text note. Long press an existing note to edit or delete it.
📐
TemplatesUse the Templates button to instantly set up a standard motor-pump or motor-fan train.
🖨️
Print / ShareExports a 3-page report: bubble chart, measurement data table, and diagnosis findings.
History
💾
Save to HistoryTap Save to History on the History tab. Up to 20 charts saved locally on this device.
⬅️
Swipe to deleteSwipe a history card left to instantly remove it.
↩️
UndoAfter deleting a component or measurement point, tap the Undo button that appears in the header.
